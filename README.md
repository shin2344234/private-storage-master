# Private Storage Master

A Crimson Desert plugin that opens Private Storage and the five housing
chests from anywhere in the world.

It picks up where two earlier mods stopped. Stevi2195's Private Storage
Anywhere ended at 1.6.0 for game 2.02.00, and jkiip's community build for
2.00 added a Private Storage capacity setting on top of an older version.
This project builds from Stevi's source and brings both lines together.

Nothing has been released yet. The plugin source is in `mod`, and
`mod/README.md` covers install, keys and building.

Credit for the original work, and the terms it is used under, are in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
